# Tracking mode is a Household choice: Projected or Recorded

Some Households only want to know what renews when, others want every charge confirmed. So each Household chooses: Projected (payments are calculated from the cycle and price history) or Recorded (each Payment is also stored as Due, Paid or Skipped, with an editable actual amount). Switching to Recorded is forward-only with no backfill, so statistics for a Household that switched mix calculated and recorded periods, and say so. Supporting both costs more than either alone, but one mode would fail half the audience.
