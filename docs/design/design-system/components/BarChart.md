# BarChart

A horizontal bar chart for costs by category, member or payment method, always next to its data table. Abonemen component (`mc-bars`).

- **The consumer provides:** labelled values in one currency and period.
- **Rules:** every bar carries its label and value as text; series colours `chart-1` to `chart-4`; the picture is `aria-hidden` and the table twin is what screen readers use.
