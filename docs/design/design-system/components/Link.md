# Link

Links take the user to another page or place and are always underlined. Utrecht Link (`utrecht-link utrecht-link--html-a`).

- **The consumer provides:** an `href` and text that makes sense out of context ("View Netflix details", not "here").
- **Rules:** hover thickens the underline to 3px; the current page in a list of links gets `aria-current="page"`; a link that opens a new window says so in its text.
