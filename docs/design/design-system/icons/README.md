The 68 Tabler Icons (outline, version 3.48.0) that Abonemen's screens use, unchanged from the `@tabler/icons` package. MIT licence, © 2020–2026 Paweł Kuna; keep the licence notice when you ship them.

Each file is 24 × 24 with a 2px stroke in `currentColor`, so the icon takes the colour of the text beside it. In the app, inline the SVG (or use `@tabler/icons-vue`) rather than an `<img>`, so `currentColor` works and Windows high contrast recolours it. Mark it `aria-hidden="true"` when a visible label sits next to it.
